# Contributing

Thank you for considering contributing to GNOME Music!

GNOME Music is free software, and it would not exist without contributions from the free
software community. We value many different kinds of contributions:

- Issue triages
- Bug reports
- Feature requests
- User experience reports
- Translations
- User interface designs
- Documentation improvements
- Code reviews
- Bug fixes
- Performance enhancements
- Source code cleanups
- Feature implementations

This list is very likely incomplete. Extending this list could be your
first contribution ;)

## Code of Conduct

When interacting with the project, the [GNOME Code of Conduct][coc] applies.

## Communication Channels

- Technical discussions happen in the issue tracker and on proposed patches directly, which are both
  hosted on [GNOME's Git forge][forge].

- Day-to-day conversations, coordination and socialising with other contributors happens primarily
  in our [#gnome-music][matrix-chat] group chat on [Matrix][matrix].

- Support for users is provided on [GNOME Discourse][discourse], in the "Applications" category,
  using the "music" tag.

## Next Steps

- Check out [GNOME Music on welcome.gnome.org][welcome], which contains concrete steps and
  instructions on how to contribute in a variety of different ways.

- Join our group chat on [Matrix][matrix]! We are happy to assist you with your contribution, as
  well as having a nice chat about all things Music :)

- If you intend to work on the source code of GNOME Music directly, you may want to check out our
  [Hacking Guide][hacking], which explains how to work with the code base in more depth.
